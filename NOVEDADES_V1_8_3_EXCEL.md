# Actualización v1.8.3 — Exportación nativa Excel

El reporte administrativo se descarga como `.xlsx`, con hojas **Evaluaciones** y **Resumen**, filtros, estilos, encabezados y formato numérico.

Despliega el ZIP completo en GitHub, incluyendo `requirements.txt` (agrega `openpyxl`). No requiere SQL.

El reporte conserva los filtros activos; las notas solo se incluyen si están oficialmente publicadas.
