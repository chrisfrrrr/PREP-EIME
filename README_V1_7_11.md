# PREP-EIME v1.7.11 — Distribución equilibrada por áreas

- El simulador reparte las preguntas elegibles por rondas entre las áreas disponibles.
- Conserva la aleatoriedad de las preguntas y del orden final.
- Si un área se agota, redistribuye los cupos entre las demás.
- Si hay menos preguntas que áreas, selecciona aleatoriamente un subconjunto.
- No modifica la base de datos ni los resultados históricos.
