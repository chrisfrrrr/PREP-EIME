# PREP-EIME v1.7.12 — Validación previa de disponibilidad

- Antes de crear un simulacro, compara preguntas solicitadas con las elegibles para la carrera, áreas y dificultades seleccionadas.
- Si hay menos preguntas, informa la reducción y desglosa disponibilidad por área, incluidas áreas con cero preguntas.
- El estudiante debe aceptar explícitamente el simulacro reducido; puede cambiar los filtros sin crear un intento.
- Si no hay preguntas o no se seleccionan áreas/dificultades, se impide iniciar.
- Se conserva el algoritmo equilibrado de v1.7.11 y no se modifican tablas ni políticas de Supabase.
